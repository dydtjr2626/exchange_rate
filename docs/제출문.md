# 제출문 — 환율 정보판 (Task 04)

> **초안입니다.** `docs/작업-정리.md`의 요청 기록(#1~#43)을 바탕으로 AI가 정리했습니다.
> 특히 ② "직접 판단한 일"과 ③ "AI 제안을 따르지 않은 일"은 본인의 판단이므로, 제출 전에 직접 읽고 사실과 다른 부분을 고쳐 주세요.

- 앱 주소: https://exchange-rate-pi.vercel.app (심사용 화면: https://exchange-rate-pi.vercel.app/?dev=1)
- 저장소: https://github.com/dydtjr2626/exchange_rate
- 확인 방법: `README.md`의 "짧은 확인 방법"

## ① AI에게 맡긴 일

| 일 | 내용 |
|---|---|
| 첫 구현 | 화면, 실패 5종 합성 재생, `T04-RECOVER-D2` 복구, 일별 기록, 서버 함수(`api/`), README 작성 (#3) |
| 키 보호 구조 | 키를 프로젝트 밖(`~/.exchange_rate.env`)으로 옮기고 서버 환경변수로만 읽게 하는 구조, 로컬 서버 `server.js` (#6, #7, #28) |
| 오류 원인 조사 | 챗봇 502 오류(모델 단종·과부하), 서버가 옛 코드로 돌던 문제, 차트 말풍선 위치 버그, 긴 답변 스크롤 문제 (#9, #10, #29, #42) |
| 데이터 원천 조사와 전환 | 한국은행 ECOS 조사, 서버 프록시 구현, 이전 원천(ECB) 기록 정리 (#26) |
| 기능 구현 | 자동 조회, 차트, 기록 표 페이지 이동, 계산기, 통화 추가, 다크 모드, 내보내기, AI 해설 도구 등 (#14~#16, #24, #30, #34~#38) |
| 보안 점검 | 키 검색, 경로 탈출 차단, 보안 헤더 추가 (`docs/보안-점검.md`) |

## ② 직접 판단한 일

| 판단 | 이유 |
|---|---|
| 환율 원천을 ECB(Frankfurter)에서 **한국은행 ECOS로 바꾸기로 결정** (#25, #26) | ECB 값이 한국 시장 값과 다르고, 오늘 조회값이 사실 전날 값이었음 |
| 달러·엔을 **같은 기준(매매기준율)**으로 맞추기 | 엔화 15:30 종가는 한국은행에 없어서 두 통화를 공정하게 비교하려면 같은 기준이 필요 |
| 개발자용 항목(실패 재생, 원자료, error_code 등)을 **`?dev=1`에서만 보이게** 하기 (#17, #18) | 일반 사용자 화면을 단순하게 유지 |
| 직접 본 시세는 **"수동 입력"으로 따로 표시**해서 넣기 (#20) | 실제 조회 기록과 섞이지 않게 구분 |
| 뉴스 연동 대신 **한국은행 지표(코스피·금리)를 근거로 쓰기** (#33, #34) | 무료로 안정적으로 쓸 수 있는 뉴스 원천이 없었음 |
| 상단 상태 표시를 **작은 한 줄로 줄이고 FRESH 문구 빼기** (#35) | 정상일 때는 눈에 띌 필요가 없음 |
| 배포 시 **Gemini 키는 넣지 않고 ECOS 키만 등록** | 공개 주소에서 AI 호출 한도·비용이 소모될 위험을 피하고, 과제 필수 요건은 환율 쪽 기능이라 충분함 |

## ③ AI 제안을 따르지 않은 일 (또는 AI가 스스로 철회한 일)

| 제안 | 결정 | 이유 |
|---|---|---|
| 구글 뉴스 RSS로 뉴스 근거 답변 (#30, #31) | 사용하지 않음 | 피드 안에 "개인 피드 리더용, 그 밖의 사용 금지" 문구가 있어 이용 조건 위반 위험 (AI가 확인 후 추천 철회) |
| 유료 NAVER API HUB 사용 (#32, #33) | 사용하지 않음 | 유료라서 |
| AI가 "오늘의 한 줄 요약" 문장을 쓰게 하기 (#39) | 코드가 수치와 문장을 모두 만들도록 변경 | AI가 "최근 30일"과 "전일 대비"를 섞고 표현을 과장하는 것을 직접 확인 |
| 과거 기록을 최근 7일만 소급 조회 (#23, #24) | 가능한 최대 기간까지 가져오도록 변경 | AI가 정한 7일 제한 때문에 기록이 끊겨 보였음 |
| 제안된 기능 목록 전체 구현 (#35) | 일부 항목은 의도적으로 제외 | 이미 있는 기능과 중복 |

## 알려진 한계

- 실제 일별 기록은 **보는 사람의 브라우저(localStorage)**에 저장됩니다. 서로 다른 KST 날짜의 실제 기록 2건은 같은 브라우저에서 날짜를 달리해 조회한 뒤 내보내기(JSON/CSV)로 제출합니다.
- 배포 환경에는 Gemini 키를 넣지 않아 AI 해설은 꺼져 있습니다. (`/api/chat` → 503, 화면에 "AI 키가 서버에 설정되지 않았습니다")
